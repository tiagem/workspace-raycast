# Workspace

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=flat-square)](LICENSE)

Search, pin, and open projects from every folder you work in.

Workspace is a [Raycast](https://raycast.com) extension, compatible with Raycast 2.0. Add workspace folders and it lists every project inside, with git status, tags, usage stats, a custom app per workspace, and a JSON backup of your setup. It shares its feature set with the sibling [workspace-vicinae](https://github.com/TiageMiguel/workspace-vicinae) extension.

## Features

- Search projects across all workspaces
- Pin projects and keep recent ones at the top
- Git branch, dirty files, stash count, and ahead/behind
- Tags with per-project assignment and filtering
- Usage statistics
- Project discovery with scan depth, ignore patterns, and marker detection
- README preview per project
- Import and export settings as JSON

## Getting started

1. Run **Manage Workspaces** and add the folders that contain your projects.
2. Set a default app (and a terminal, if you want) in **Workspace Settings**.
3. Open **Workspace**, search, and hit enter.

## Commands

- **Workspace**: Search and open projects
- **Manage Workspaces**: Add, remove, and reorder workspace folders
- **Workspace Settings**: Apps, git status, tags, discovery, backup, and reset
